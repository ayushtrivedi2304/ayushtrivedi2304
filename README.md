## 💡 Featured Project

### 🗑️ SwachhLens

**SwachhLens** is an AI-powered waste analysis system designed to identify and analyze waste-related scenes from images.

The project combines computer vision models to detect waste, analyze the surrounding scene, and identify different types of waste.

**Key areas:**

- Computer Vision
- Object Detection
- Image Classification
- AI-powered image analysis
- FastAPI backend
- YOLO-based waste detection

🔗 **Repository:** [SwachhLens](https://github.com/ayushtrivedi2304/swachhLens)
